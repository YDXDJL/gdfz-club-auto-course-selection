# 广大附中社团自动选课程序

面向广州大学附属中学超星选课页面的 Python 桌面工具，支持课程报名与收藏、多账号 Cookie、定时发送和轮次控制。

## 功能

- **报名 / 收藏**：两种操作均保留，使用同一套课程与账号设置。
- **课程分类与搜索**：按全部、选修课、社团课筛选，支持名称和课程 ID 搜索，也可手动填写 ID。
- **多账号**：逐个或批量添加 Cookie，每轮每个账号各发送一次，最多 8 个账号并行。
- **定时与轮次**：北京时间支持 `YYYY-MM-DD HH:MM:SS.fff`，可设置发送轮数及轮间等待毫秒数。
- **状态提示**：按照 JSON 中的布尔值 `status` 显示成功、失败或待核对，并记录请求开始时间、耗时与响应。
- **取消任务**：可取消定时或停止后续发送；已经发出的请求会继续返回结果。

## 运行

推荐 Windows、Python 3.12。程序只使用 Python 标准库，需要可用的 Tkinter。

下载仓库并解压后，在该目录执行：

```powershell
py -3 course_app.py
```

也可双击 `启动程序.bat`。使用其他系统时，可运行 `python3 course_app.py`；Linux 需自行安装系统提供的 Tkinter 包。

## 使用步骤

1. 选择“报名”或“收藏”，筛选并选择目标课程。
2. 在已登录选课网页的开发者工具中，从 **Network → 请求 → Headers → Request Headers** 复制完整 Cookie 值。
3. 填写账号备注及 Cookie 后点击“添加”；批量添加时每行一个完整 Cookie。
4. 设定轮数与轮间等待时间，点击“预览任务”检查课程、账号数量和总请求数。
5. 点击“立即开始”，或填写未来的北京时间并点击“启动定时”。
6. 查看账号表和逐轮日志，最终状态可以在网站收藏列表或已选课程中核对。

所有已添加账号均参与发送，选中账号行只用于移除账号。所有账号使用当前选定的同一门课程、同一种操作。

## 轮次与时间含义

例如 3 个账号、4 轮：未取消且无任务级异常时，共发送 12 次请求。前一轮全部请求完成后，才开始等待设定的轮间间隔。成功账号仍会继续参与后续设定轮次。

时间输入与日志保留三位毫秒。Windows 任务运行期间请求 1ms 定时器分辨率，结束后配对恢复；定时时刻之前预热工作线程。**这不保证服务器恰好在指定毫秒收到请求**，实际时间还受系统调度、网络与服务器排队影响。

定时期间请保持程序运行、电脑唤醒、网络连通。关闭程序后不会在后台继续定时。请求超时为 20 秒，网络超时的结果标记为“待核对”。

## 课程目录

内置活动 `3389` 的课程快照，采集日期为 **2026-09-12**：选修课 35 门、社团课 21 门，共 56 门。

页面标题标称 86 门，但采集账号的目录接口实际只返回 56 门。内置目录包含这次接口返回的全部课程，不将页面总数当作该账号的可见数量。

添加账号后，可以点击“刷新全部账号可见课程”合并各账号正常可见的课程。刷新仅保存课程资料，不保存 Cookie；任一账号刷新失败时保留原目录。

## 结果判断

| 提示 | 条件 |
| --- | --- |
| 成功 | HTTP 为 2xx，且 JSON 的 `status` 是布尔值 `true` |
| 失败 | HTTP 非 2xx，或 JSON 的 `status` 是布尔值 `false` |
| 待核对 | 缺少布尔值 `status`、非 JSON 响应、网络异常或超时 |

HTTP 200、字符串 `"true"`、字符串 `"false"` 都不会单独被当作业务成功。

## 数据与凭据

Cookie 只存储于当前进程内存；不写入配置文件或日志，关闭后需要重新添加。界面会清理 `Cookie:` 前缀和 Markdown 下划线转义。仓库只含程序、课程快照和模拟测试数据，不包含真实登录 Cookie、账号令牌或浏览器会话。

点击开始会实际执行所选报名或收藏操作。

## 测试

```powershell
py -3 -m unittest discover -s tests -v
```

测试使用 `127.0.0.1` 模拟服务与虚构 Cookie，不请求学校网站。覆盖 HTTP 请求格式、状态判断、多账号轮次、间隔、定时、取消、课程分类分页和界面操作逻辑。

截至本版本，12 项测试通过。已有单账号收藏成功实测；未验证正式报名成功，也未对学校网站执行多账号定时测试。
